Pin–Slot Assembly Gauge Calculator

Worst-case fit check between Part L and Part U with shoulder bolts, and functional go-gauge sizing for both suppliers. All values in mm. Part features use position/perpendicularity at MMC with datums B and C at MMB. Gauge tolerances are applied so that a gauge error can never pass a bad part.

Inputs

Fit results (worst case, drawing limits)

Minimum radial gaps. A negative value is an interference; its absolute value is the maximum interference. The shank result assumes the datum reference frames of both parts coincide and takes no credit for the remaining pin play, so it is conservative. Gauge tolerances and wear do not enter the fit results.
